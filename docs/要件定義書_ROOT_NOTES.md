|---|---|---|

| C-04 | 進行データ（灯った星・発見・連続プレイの残り回数・アーティファクト）を無断で消したり、サーバーへ自動で送ったりしない | 成果を失わず、端末の中だけで遊べる前提を守る |
| C-05 | 伝承（鍛冶屋のハンマー、天球の音楽、一弦の琴、√2の秘密、ヒッパソスの話など）を現実の事実として示さない。「〜と伝えられている」の形で語る。ゲームの創作（鐘・封音・教団の封印・精霊など）を伝承や史実のように見せない | 数学・音を題材にする作品の信頼を守るため |

## 2. 背景・目的

星が鳴らすお題の和音を聞き、**その響きを生む三角形を、棒を選んで逆引きする**パズルゲームを作る。三角形の3辺は弦で、形がそのまま和音として鳴る。音と図形が同じ「長さの比」でつながっていることを、説明なしで体験してもらう。

発想の起源はピタゴラスの逸話（鍛冶屋のハンマーの音、一弦の琴、整数の比、三平方の定理、√2）と、天球の音楽の考え方。ゲームでは、鍛冶場でハンマーが打った鐘が鳴る形に置き換える（ハンマーそのものは鳴らない）。史実の解説ではなく、寓話として世界観に使う（C-05）。音（鐘・一弦の琴）から始まり、最後に三平方の定理と√2で締める流れにする。

**設計の芯（薬味の考え方）**：単体では濁って聞こえる音も、流れの中では意味を持つ。食べ物の薬味のように、濁った音が曲を引き立てる。1〜3章で整数の比の美しい響きを作り、最後に「封じられた濁る音」を流れの中で生かす。

想定プレイヤーはシリーズと同じ大人向け。理系ではなく、高校で習ったが覚えていない人【想定】。音楽経験が少ない人も楽しめることを目指す。

## 6. 主要な流れ

### 6.1 三角形のステージ（第2・3章）

1. 星が瞬いて、お題の和音が鳴る（何度でも聞ける）
2. 棒を3本使って、三角形を作る。棒の操作は2段階：1回目のタップで選ぶ（その棒の単音が鳴る）、もう一度タップで使う（使っている棒なら外す）。3本そろっているときは勝手に入れ替えず、先に外す棒を選ぶ（v0.15）。2回目を「間があいてもよいタップ」にするか「ダブルタップ」にするかは、実機で比べて決める【要確認】。選んでいる棒は、使う＝金色、外す＝赤みのある色で示す（v0.17）
3. 辺をタップ、または指でなぞって、1音ずつ確かめる
4. 連続プレイのフリーでは、和音で鳴らしたり、お題と交互に比べたりできる（それ以外の遊び方では回答まで和音は鳴らせない）
5. 納得したら「回答する」。正解なら澄んだ和音が鳴り、三角形が混ざった色で光り、星が灯る
6. 発見の条件を満たしたら、巻物に記録して知らせる

### 6.2 第1章：一弦の琴

- 駒を指で大まかに動かし、「微調整つまみ」でゆっくり詰める。微調整つまみは駒をゆっくり動かすもので、張りは変えない（C-01）
- お題の単音と自分の弦が同時に鳴り、揺れが消えたら合格（5章）
- 合格すると、弦の上に比を表示する

| ステージ | お題の音 | 駒の位置（答え） |
|---|---|---|
| 1-1 | 弦全体の1オクターブ上 | 1/2 |
| 1-2 | 5度上 | 2/3 |
| 1-3 | 4度上 | 3/4 |
| 1-4 | 長3度上 | 4/5 |
| 1-5 | 短3度上 | 5/6 |

導入は鍛冶場の鐘の言い伝えで始め、「弦で確かめる」流れにする。お題の単音は弦で鳴らす（鐘の音色の倍音が、うなりの聞き取りを邪魔しないため）。ハンマーの重さで音が決まるとは示さない（C-05）。

### 6.3 章末の謎ステージ（アーティファクトを手に入れる）

- 各章の最後に謎ステージを1つ置き、アーティファクト（盾・剣・鎧）を1本ずつ手に入れる（盾＝第1章、剣＝第2章、鎧＝第3章。6.8）。
- 謎は「装備から漏れる封音の声を聞いて、同じ高さの弦を選ぶ」形（v0.9で「星の単音」から変更）。謎を解くことが、封じられた声を見つけることになる。説明文の知識ではなく、耳で解ける問題にする（第4章の試作で、知識を前提にした謎は伝わらなかったため）。
- 封音の反応は、選んだ弦に左右させない（正誤が漏れないため）。声は選ぶ前に漏れ、持ち帰ったあとの反応は正誤にかかわらず同じにする。
- 間違えた辺を持ち帰っても、キャラは同じで、声だけがずれている。最終章で合わないと分かり、ZAPで「本当の声」を取り戻しに戻る。
- 答えはその場で正誤を示さず、選んだ長さの辺がそのままアーティファクトになる。間違えていても、最終章のZAPで戻って解き直せる。
- おとりの辺（試作では7と10）も、旅の途中で手に入る【手に入れ方は要確認（Q-13）】。

### 6.4 最終章：アーティファクトを使って扉を開く

旧案（第4章の中だけで謎を解いて辺を集め、最後に組み合わせる）は【失効】（2026-11-13、v0.5）。試作で、説明だけでは意味が分からなかったため。

**流れ**

1. 最終章に入る。入った時点で、課題を解くのに必要な辺がそろっていなければZAP
2. 課題（門）を順に解く。各課題では、与えられた2辺に手持ちから1本を足して、門の響きと同じ和音を作る
3. 手持ちには当てはまりそうな辺（三角形が閉じる辺）が複数あるが、正しいのは1本だけ。単音を聞き比べて選ぶ
4. 使った辺はなくなる。正しければ門が開き、報酬の辺がもらえる
5. 最後の課題の報酬は巻物「等しき二本を、直角に開け」。報酬の辺2本（同じ長さ）を直角に開くと、整数では書けない斜辺（n√2）が生まれ、封印の三角形ができる
6. 扉が開き、伝承を語ったあと、集めた音で曲を締めくくる（6.5）

**間違えたとき**

- 間違った辺を使うと、その辺はなくなる。辺がなくなること自体を罰とし、失敗上限は使わない
- そのせいで、この先の課題が解けなくなったら、その時点でZAP

**ZAP**

- 足りない辺（剣・盾・鎧）を手に入れる**元の謎にだけ**戻される。足りない辺が2本以上あれば、1回のZAPで順番に全部回る
- 謎を解き直したら、最終章を**初めから**やり直す（手持ちは、最終章に入る前の状態＋解き直した辺）
- ZAPのたびに、プレイ全体の失敗上限を1つ使う
- ヒントありでは、足りない辺の名前を教える

### 6.5 コード進行と曲

### 6.9 時代と、シリーズとのつながり（2026-11-14 決定）

- 時代順：**伝承の時代（鍛冶場・封印）→ PRISM NOTES → ROOT NOTES の旅**
- 序の切り替えで「長い時が流れた」とし、今の旅へ移る
- 序で一言だけPRISMの鐘をほのめかす（例：「ハンマーが打った鐘たちは、遠い祭壇で星の光に鳴らされているという。ひとつひとつは澄んだ一音。重なるのは、余韻だけ」）。結末では「遠い祭壇で、鐘の余韻が、いつもと少し違う重なり方をした」で止める。「プリズム」という名前は出さない
- 結末で「教団が封じた音は、ほかにもあるという」と一言だけ残す（シリーズへの余白）
- 物語の場面の鐘は、PRISM NOTESの鐘の音色（2オペレーターFM）で鳴らす。聴感で問題があれば変えてよい（A区分）。→ 2026-11-15 発案者：PRISM の鐘（√2 の FM）は重ねると濁るため、倍音が整数倍に並ぶ FM（変調の倍率1）に、打った瞬間のキラッとしたアタックを足した音へ変更（試聴ページ public/audition/bell.html の「K1＋キラッ（弱）」）。裏設定の「PRISM の鐘は√2で鳴っている」はそのまま（物語の中の鐘の音色だけを変えた）。遊ぶ部分は弦の音色のまま

**裏設定（ゲームには出さない）**
- ハンマーが打った鐘のいくつかが、のちに遠い祭壇（PRISM NOTESの鐘）へ運ばれた
- 祭壇の鐘が澄んだ単音で鳴るのは、9と8の濁りを抜いて鍛えたから。和音になるのは余韻が重なったときだけ

### 7.1 表現の申し送り

- **世界観：** 秘密の教団・夜空。夜の神殿、五芒星、星空に張られた弦、鍛冶場の跡。主役は物（鐘・装備）で、案内は弦の精霊（6.8）。フロート・ノーツ（人物が主役の紙芝居）とは雰囲気を変える。
- **画面：** スマホで**スクロールせずに遊べる1画面**。上＝星とお題、中央＝三角形（画面の高さに合わせて伸縮）、下＝棒と操作ボタン。補助の情報（巻物、設定、遊び方）は引き出しにまとめる。試作の配置を基準にする【想定】。第1章と謎ステージの画面は基本設計で決める。**横向きにも対応する**（2026-11-14 発案者）。横向きでもスクロールせずに遊べる1画面にする。横向きは、左に三角形、右に星・棒・操作の2列にする（v0.13）。
- **タイトル画面：** SIKUMI NOTES | 04 の形式を前作にそろえる【想定】。
- **音色：** 遊ぶ部分の弦は、倍音が整数倍に並ぶ音色にする（試作はのこぎり波）。物語の鐘はPRISMの鐘の音色を使う（6.9）。最終の音色は実機で決める（A区分）。
- **結末：** 封じられた音が流れの中で開放され、神々も満足するほど美しく響く、前向きな締めくくりにする（6.4）。

## 11. リスク

| リスク | 対応 |
|---|---|
| 音楽経験のない人には聞き分けが難しい | 単音で確かめる流れ、選択プレイとフリー、メーターで支える。実機で確かめる |
| 整数の棒では、ゆっくりした揺れがほとんど出ない（隣の長さでも音が1割以上離れる） | メーターは「遠い／近い」の目安として使う。揺れの手応えは第1章の調律で体験させる |
| 棒の色がお題の手がかりになりすぎる | 実機で確かめ、必要なら色を弱める（A区分） |
| ZAPが重く感じられる | 戻るのは足りない辺の謎だけにし、答え直しに時間がかからないようにする。選択プレイとフリーでは足りない辺の名前を教える |
| 最終章のルールが伝わらない（第4章の試作で一度起きた） | 6.7の決まりを守る。試作で「説明なしで意味が分かるか」を確かめてから作り込む |
| メジャーの純正な三角形が少なく（2〜24で計5通り）、同じ形が続く | 進行の並びで気になるかを実機で確かめる。必要なら長さの範囲や広がりの条件を見直す（B区分） |
