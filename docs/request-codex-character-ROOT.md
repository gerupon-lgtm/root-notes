# Codex への依頼：ROOT NOTES のキャラクターデザイン

2026-11-14 Claude 作成。発案者の依頼により作成しました。発案者が、この依頼書をもとに Codex へ依頼します。

## 1. 作品の概要

ROOT NOTES（ルート・ノーツ）は SIKUMI NOTES の04作目です。星が鳴らす和音を聞き、その響きを生む三角形を、長さの決まった棒（弦）を選んで作るパズルです。三角形の3辺は弦で、形がそのまま和音として鳴ります。

物語は、ピタゴラスの「鍛冶屋のハンマー」の伝承を土台にした、ゲーム独自の寓話です。

- 昔、鍛冶場でハンマーが打った4つの鐘（大きさ12・9・8・6）のうち、9と8の鐘を重ねると濁った。
- 教団はその濁った音を「不浄の響き」と呼び、盾・剣・鎧の装備に封じて各地に散らした。
- 長い時が流れ、天の歌（星の響き）が欠けている。プレイヤーは各章の終わりで装備を見つけ、最終章で封じられた音（封音）を解き放つ。
- 濁りとされた音は、曲の流れの中で「導きの響き」に変わる。

**主役は物（鐘と装備）です。** 人や神々は登場しますが、物の後ろに薄く見える背景です。案内役は「弦の精霊」です。

| 名前 | 内容 | 目安 |

## 5. キャラクターの性格（絵の手がかり）

| キャラ | 性格 |
|---|---|
| 弦の精霊 | 静かで、ていねい。答えを教えず、耳を澄ますことを促す。かつて一弦の琴に宿っていた |
| 盾 | 守りきれなかった記憶があり、慎重で心配性 |
| 剣 | 傷つけてきた記憶で翳りがあるが、本当は優しい。寡黙でまっすぐ。**悪役や怖い印象にしない** |
| 鎧 | 傷を全部受け止めてきた、おおらかな年長者 |

装備は顔を描かず、形・光・傷・封印の具合で性格を出す案をおすすめします。顔を付けたほうが良ければ、比較案として出してください。

## 6. 守ってほしいこと

- **世界観：** 夜空、夜の神殿、静けさ。PRISM NOTES の静かな雰囲気に近づける。FLOAT NOTES のクレヨン調の紙芝居とは変える。
- **主役は物：** 鐘と装備を手前に大きく。人や神々は後ろの薄い影にする。
- **時代の見分け：** 伝承の時代の場面は色を落とし、今の場面は通常の夜空の色。文を読まなくても分かること。
- **状態の見分け：** 封印中と解放後が、色だけでなく形や光でも分かること。消音でも分かること。
- **鐘の大きさ：** 12・9・8・6 の比を守る。大きさが音の高さに対応するため。
- **星の精霊：** PRISM の採用案（星空の衣の小さな人型）に合わせ、新しくデザインし直さない。
- **文字：** 絵の中に説明文を焼き付けない。文言は画面側で変えられるようにする。
- **伝承と創作：** ピタゴラスや鍛冶屋の伝承は伝承として扱い、鐘・装備・教団の封印・精霊はゲームの創作。歴史の資料のように見せない。
- **独自性：** 既存の作品のキャラクターや場面に似せない。
- **スマホ優先：** 縦画面が基本。確認端末は Pixel 6a と iPhone XR。小さく表示しても形が読めること。
- **容量：** 配信する絵は軽くする。透過 PNG または SVG。候補の原本は、リポジトリに入れなくてかまいません。
- **変えてよい範囲：** 絵柄・色・配置は発案者の指示で変えてかまいません（要件定義書0章のA）。キャラの性格や物語の筋を変える提案は、発案者に相談してください。
