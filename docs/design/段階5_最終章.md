# 段階5 設計メモ：最終章（門と扉）

2026-11-15 作成。正典は要件定義書 6.4（v0.24 で決めた8つ）・6.7・6.10・C-03。発案者「キャラが足りない部分は一旦プレースホルダーで」。

## 1. 流れ（連続プレイ）

鎧の謎のあと → 最1（門の前。新しい決まりを精霊が話す）→ 手持ちに足りない武具があれば ZAP → 門ごとに：最2（門の前・武具の声）→ 門（遊ぶ）→ 最3（門が開く）→ 最3'（小部屋：封音が初めて話し、報酬を差し出す）→ 3つ目のあと「奥への道が開きました」→ 最4（最後の扉・巻物）→ 扉（直角に開く）→ 結末 最5〜最9 →「おしまい」→ タイトル。続きの保存は最後まで通したら消す

## 2. 遊び（`src/game/final-play.js`・`src/ui/final-screen.js`。試作 docs/prototypes/final-chapter.html と同じ流れ）

- 手持ち：章末の謎で持ち帰った武具（選んだ長さ。盾・剣・鎧の札）＋拾った弦（第2章で 7、第3章で 10。章の終わり 終4 で精霊が拾う）
- 門：門の辺2本（点線の枠。選べない）＋手持ちから1本。辺をタップで単音、「門の響きを聞く」、「重ねて鳴らす」（門の辺2本と選んだ辺。フリーだけ）、「この弦を差し出す」。差し出した辺はなくなる。正しければ門が開く。違えば「門は応えません」と画面が揺れ、辺は門に残る
- 報酬：盾・剣の門＝辺6（扉用。門には使えない）、鎧の門＝巻物
- ZAP：この先の門が解けなくなったら。合わない声の紙芝居（フリーは足りない武具の名前を出す）→ 足りない武具の謎だけを解き直す → 最終章を初めから。ノーマル・エキスパートは ZAP のたびに失敗の残りを1つ使う（最終章に入ったときの残りは第3章の続きから。0 になったらゲームオーバー）
- 扉：同じ長さの扉用2本を選んで「直角に開く」。直角三角形と各辺の正方形（36・36・72）を描き、「36 ＋ 36 ＝ 72　斜辺は 6√2」。音は 6・6・6√2
- 基準の音：謎・鐘と同じ（大きさ12の鐘＝ファ）。門の響き：盾 B♭・C・F（sus4）、剣 F・A♭・C（Fm）、鎧 F・C・F
- 機械検査（C-03。`tests/final.test.js`）：各門で正しい武具を使えば閉じる、手持ちの正解は各門でちょうど1本、謎の答えと門の答えが同じ長さ、おとりの辺もどこかの門で閉じる

### プレースホルダー（あとで差し替える所）

- 星の精霊（PRISM 原本を最8 に薄く置く）：まだ置いていない
- 締めくくりの曲（最7）：今は第2章の曲を流しているだけ。リズム・メロディ・オブリガートと、武具の音・√2 の V7→I は「直す予定の一覧」の相談中の件
- 最6 の Fsus4 → F：今は鐘4つ（F・B♭・C・F）を一緒に鳴らすだけ
- 語り：すべて仮。封音の言葉も仮（要件6.8 の性格に合わせた案）
- 拾った弦の場面：終4 の精霊のセリフに一言足しただけ（絵はない）

## 5. その後の直し（v0.9.34、2026-11-15 発案者）

- 門で弦を差し出すと音が切れていた：和音を鳴らし終えて（1.6秒＋結果を出すまでの待ち）から紙芝居へ移る。ZAP も同じ
- 最後の扉の巻物：「ひとしき二本を、」（改行）「直角に開け」。字は絵の幅に合わせて大きく太く
- 結末 最5：「〜落ち着かない新入り「√2の響き」です。封音たちが少し戸惑っています。」。√2の響きの絵を大きくし、和音が鳴っている間（2.6秒）光らせる
- 結末 最6：「「濁りは流れの中に置けば道しるべになる。」」（改行）「鐘たちがそろって鳴りました。」
- 結末の最後のボタンは「エンディング作成中」。エンディングの演出と最終章クリアの曲（第2章の曲＋リズム・メロディ・オブリガート）は相談中（直す予定の一覧）
