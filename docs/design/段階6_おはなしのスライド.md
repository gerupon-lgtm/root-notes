- **門は並列。** 1つの広間に3つ横に並ぶ。3つは最後の扉にかかった封印で、全部開くと奥へ進める。開く順は左から盾 → 剣 → 鎧。背景ごと差し替えるので、扉だけを動かす演出はできない。上の枠の三角形の印は門の番号の飾り（課題の辺の比ではない）。配信用の絵は印を含むので、印の部品を重ねない
- **3つ開いたあと**、精霊の語りで「奥への道が開いた」と伝える（絵の描き直しは要らない）
- **星空なしの絵の使い方**：後ろに不透明な夜空の地色とコードの星、手前に透明の絵を、同じ位置・同じ大きさで重ねる。手前の絵は薄くしない（壁から星が透ける）。この1枚専用（扉が開いた絵には使えない）
- **小部屋（2026-11-15 発案者が決定）**：門が開くと、使った装備は自分の門の先の小部屋に残り、封印が解けた姿で話し、報酬（盾・剣は辺6、鎧は巻物）を差し出す。「使った辺はなくなる」の理由を、説明なしで見せる
- 報酬の「辺6」の絵（1点を2本に使い回す）と、小部屋に重ねる門の印（印1〜3を個別の部品で）は Codex に依頼（2026-11-15 発案者。`request-codex-reward-and-chamber-ROOT.md`）。印で、どの門の先の部屋か分かるようにする
- **納品（v0.6.0、2026-11-15）**：`ROOT_NOTES素材/物語素材/v0.6.0/delivery/` の `reward-edge-6`（2060×121）、`chamber-mark-1〜3`（透過 PNG・WebP）。配置の数値は `placements.json`（どれも案）
