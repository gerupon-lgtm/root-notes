# 段階5 設計メモ：章末の謎（盾・剣・鎧）

2026-11-15 作成。正典は要件定義書 6.3（章末の謎）・6.4（最終章・ZAP）・6.8（キャラクター）。実装は `src/content/riddles.js`（中身）・`src/ui/riddle-screen.js`（画面）。

## 1. 遊び方

武具（封印中）から漏れる封音の声を聞き、同じ高さの弦を4本から選ぶ。「この弦を持ち帰る」で決めると、選んだ長さの辺がそのまま武具（アーティファクト）になる。その場では正誤を出さない（間違えていたら最終章の ZAP で戻る）。

- 弦をタップ：選んで単音を鳴らす
- 「声を聞く」：武具の声をもう一度
- 「重ねて聞く」：声と選んだ弦を同時に鳴らし続ける（第1章の「重ねて鳴らす」と同じく、うなりで合わせる）。もう一度押すと止める
- 声は、選ぶ前にも何度か自然に漏れる（要件6.3）
- 決めたあとの反応は、正誤にかかわらず同じ

## 2. 決めたこと（2026-11-15 発案者：おすすめの7つで決定）

| # | 項目 | 決定 |
|---|---|---|
| 1 | 声の高さの基準 | 序章の鐘と同じ（大きさ12の鐘＝F4）。周波数＝K÷長さ。盾9＝鐘9と同じB♭4、鎧4＝鐘8の1オクターブ上のC6、剣5＝A♭5 |
| 2 | 声と弦の高さ | 同じ高さ（オクターブ違いにしない） |
| 3 | 声の出方 | 盾：何度も途切れる。剣：短く一度、暗い音色（「低く」は高さでなく音色で表す）。鎧：長く静かに |
| 4 | 選ぶ弦 | 答えを含む4本。答えの近くの高さで、答えのオクターブ違いは入れない。盾 8・9・10・12、剣 4・5・6・7、鎧 3・4・5・6 |
| 5 | 比べ方 | 単音・声を聞く・重ねて聞く |
| 6 | 遊び方による違い | フリーは揺れメーター（揺れの回数/秒）を出す。ノーマル・エキスパートは耳だけ |
| 7 | 決め方 | 「この弦を持ち帰る」で決める。決めるまでは何度でも選び直せる。謎は連続プレイの物語の中だけ（選択プレイの章選びには出さない） |

## 4. 絵と音

- 絵：新しい絵は使っていない。背景（盾＝鍛冶場の跡、剣＝星のない夜空、鎧＝夜の神殿の入口の回廊）、武具（封印中 v0.4.1）、声の形（v0.2.0 の SVG。声が漏れるたびに光る）
- 声の音色：`sealClear`・`sealDark`（`src/content/timbres.js`）。弦の音（オルガン）と聞き分けられる、こもった声
- 弦の音色：第1章と同じオルガン。**発案者の意向で、あとで弦楽器らしい音色に変える予定**（2026-11-15「オルガンは弦楽器ではないので違和感がある。今は考慮不要」）

## 5. まだのこと

- **実機の指摘（2026-11-15 発案者、Pixel 9a、v0.9.21）**：第1章の終わり（盾の謎）で弦を選んだとき、画面が不自然に動く。弦のあたりがパッと動いて違和感がある（発案者も細かくは見られていない）。まずはメモのみ、まだ直さない
  - **直した（v0.9.22）**：原因は2つ。①弦を選ぶたびに弦の図を全部描き直していた、②持ち帰ったあとの文が短くなって折り返しがなくなり、弦が上に詰まった。弦の図は始めに1回だけ描いて選んだ印だけを付け替え、案内の文は始めの文と持ち帰ったあとの文の高い方に高さを固定、フリーの揺れメーターも場所を取っておく形にした。あわせて、選んだ弦を行全体の金の帯と枠・太い金の弦で示し、弦の並びを謎に入るたびにランダムにした（発案者「答えが上から2番ばかり」）
  - 当時の原因の見当：弦を選ぶたびに、弦の図（SVG）を全部消して描き直している（`riddle-screen.js` の `render()` → `drawBars()`）。木目の模様と真鍮のピンの絵も作り直すので、一瞬、絵が抜けたり位置がずれたりして見える可能性がある。直すときは、選んだ印（`.chosen`）だけを付け替える形にする
