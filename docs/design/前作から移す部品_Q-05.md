## 4. 音で気をつけること

- **PRISM の鐘の中身（確認済み、ソースで読んだ）：** 搬送波 f に、f×√2 の変調波をかける。変調の深さは 5.2 から約0.4秒かけて 0.9 へ弱まる。長さ2.62秒。打った瞬間に、2倍の高さの短い音（0.06秒）を重ねる。倍音が整数倍に並ばないので、鐘らしく聞こえる。
- **PRISM の音色 strings は弦に使わない：** のこぎり波2本を ±5セント（合わせて10セント）ずらして厚みを出している。2本の間に自前のうなりが出て、196Hz で約1.1回/秒、440Hz で約2.5回/秒（計算で確認）。第1章の合格条件「揺れ1秒に1回未満」とぶつかり、お題とのうなりが聞き分けにくくなる。弦は試作と同じ「のこぎり波1本＋高音を少し削る」を土台にする案。
- **余韻の重ね方：** 要件6.5のとおり、PRISM の「0.5秒未満は直前の高さにそろえる」決まりは持ち込まない。重ねる・止めるの切り替えは `ownedVoice` の止め方で作る。
- **鐘の音色が物語で聞き取れるか**（9と8の濁り、余韻）は Q-17。段階6で、発案者の PC にある鐘の資料（試聴音源）と聞き比べる。
