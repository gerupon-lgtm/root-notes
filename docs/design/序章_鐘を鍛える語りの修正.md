# 序章：鐘を鍛えてから響きを確かめる

発案者が承認した語りの修正。文言の変更（A区分）。

ハンマーは鐘を鍛えるために登場し、できあがった鐘を鳴らして響きを確かめる。旧文は鍛冶場で演奏するようにも読め、作る工程と試す工程のつながりが抜けていた。

承認された四文を、既存の序章1〜3へ次のように割り振る。

| 場面 | 語り |
|---|---|
| 序章1 | むかし、ある鍛冶場でハンマーを振るって鐘を鍛えていました。できあがった鐘を鳴らすと澄んだ音が響きました。 |
| 序章2 | 二つずつ重ねて鳴らすと美しい響きが生まれました。 |
| 序章3 | ところが大きさの近い二つの鐘を同時に鳴らしたときだけ、響きが濁ったのです。 |

序章5の「打たれた鐘」も「鍛えられた鐘」にそろえる。

8場面の構成、絵と配置、単音・二鐘の音程と時刻、封音、進行、計算・判定、保存は変更しない。鍛える工程の新しい効果音は追加しない。実装は `src/content/story.js`、表示・読込版は0.9.42。
