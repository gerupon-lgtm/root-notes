# 段階5 設計メモ：第3章「長調と短調」（光と影の組）

2026-11-15 作成。発案者が A案（光と影の組）と、決めること1〜5をおすすめのまま決定。「なぜこうなるか」を見せるスライドは、遊べる形を作ってから一緒に組み立てる（発案者）。

## 1. 考え方（構想 2026-11-11「長調・短調の鏡写しを見せ場にする」）

長さと音の高さは反比例する。辺の比 10:12:15 の三角形は長調（周波数の比 4:5:6）、辺の比 4:5:6 の三角形は短調（周波数の比 10:12:15）。
光の三角形の「周波数の比」を、そのまま辺の比にした三角形（鏡写し）は短調になる。基準の音 K を光と同じにすると、影はちょうど光の**平行調の短調**になり、2本は同じ棒（同じ高さ）のまま、1本を替えるだけで明るい響きが影の響きに変わる。

| 光（長調） | 影（平行調の短調） | 共有する棒 |
|---|---|---|
| 10・12・15（基本形） | 12・15・18 | 12・15 |
| 15・20・24（第1転回形） | 15・18・24 | 15・24 |
| 12・15・20（第2転回形） | 9・12・15 | 12・15 |

（例：ハ長調 10・12・15 → イ短調 12・15・18。10 を 18 に替えるだけ）

鏡写しは1つの組に2つあることがある（10・12・15 → 8・10・12 はホ短調）。平行調になるもの、閉じるもの（6・9・15 は 6+9=15 で閉じない）、トップノートが C5 以下のものだけを使う。

## 3. 実装

- 曲を作る：`src/core/stage-gen.js` の `buildRun({ progression: 'mirror', key, seed, decoys })`（MIRROR・mirrorLengths・buildMirrorRun）。影のステージは光と同じ K。影の根音は純正律で積んだ高さなので平均律から少しずれ、ベースはその根音にちょうど合わせる（bassCents）。各ステージに side（'light'／'shadow'）と、影には mirrorOf（光の小節）
- 機械検査：`tests/mirror.test.js`（全キー×30種：影は平行調の短調・2本共有・同じ K・ベースと根音がオクターブ・同じ響きの別の三角形がない）
- 画面：第2章と同じ画面（`stage-screen.js` の start に chapter: 'ch3'）。見出しは「第3章 長調と短調」。影の面のうっすらした三角形は drawGhost
- 流れ・保存：`flow.js` の ch3 を三角形の章に。続きは run.ch3、選択プレイの灯った星は select.ch3
