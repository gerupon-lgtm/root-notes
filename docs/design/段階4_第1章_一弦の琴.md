# 段階4 設計メモ：ゲームの流れの骨組みと、第1章「一弦の琴」

2026-11-14 作成。発案者の依頼「ゲームの最初からの流れを実装に落とし込む」を受け、実装指示書の段階4（第1章）から始める。この段階で、序から最終章までの**流れの骨組み**も作る。中身がまだない場面（序の絵とセリフ、章末の謎、第3章、最終章）は、仮の1画面で通り抜けられるようにする。

## 1. 完了条件

- AC-09：確認端末で、第1章の調律を微調整つまみで合格まで合わせられる（発案者が Pixel 9a で確かめる）
- 連続プレイで、序 → 第1章 → 第2章（今の三角形の8つの星）の順に進める
- 自動テスト：第1章の計算（長さと周波数、揺れ、合格の判定）

## 2. 前提（要件で決まっていること）

| 項目 | 決まり | 要件 |
|---|---|---|
| 音の高さ | 駒で区切った長さ r（弦全体＝1）の部分が鳴る。f ＝ 弦全体の音 ÷ r。張りは変えない | C-01、5章 |
| 操作 | 駒を指で大まかに動かし、微調整つまみでゆっくり詰める | 6.2 |
| 比べ方 | お題の単音と自分の弦を**同時に**鳴らす | 5章 |
| 合格 | 揺れ（2つの周波数の差、回/秒）が1秒に1回未満の状態を、1秒保つ | 5章 |
| 合格のあと | 弦の上に比（1/2 など）を出す | 6.2 |
| ステージ | 1-1 1オクターブ上（1/2）、1-2 5度上（2/3）、1-3 4度上（3/4）、1-4 長3度上（4/5）、1-5 短3度上（5/6） | 6.2 |
| 遊び方ごとの違い | 選択・フリー：揺れメーターを使える。ノーマル・エキスパート：耳で合わせる【想定】 | 6.6 |
| 音色 | 遊ぶ部分の弦は、倍音が整数倍に並ぶ音色。お題も弦で鳴らす（鐘の倍音がうなりの聞き取りを邪魔するため） | 6.2、7.1 |

## 3. ゲームの流れ（骨組み）

```
タイトル
 ├ 連続プレイ（フリー／ノーマル／エキスパート）
 │   序 → 第1章 一弦の琴（5面）→〔章末の謎：盾〕→ 第2章 三角形（8つの星）→〔謎：剣〕→〔第3章〕→〔謎：鎧〕→〔最終章〕
 └ 選択プレイ
     章を選ぶ（第1章／第2章）→ その章の面を選ぶ
```

- 〔 〕は、この段階では中身のない仮の1画面（「この先は準備中」と、次へ進むボタン）。謎と最終章は段階5、序の絵とセリフは段階6で作る。
- 序は、この段階では文字だけの仮の画面にする（6.10 の8場面の見出しを並べ、「はじめる」で第1章へ）。2回目からは飛ばせる（6.10）。
- 失敗の上限・メーターの回数は、プレイ全体で数える決まり（6.6）なので、章をまたいでも引き継ぐ。

## 4. 第1章の画面

試作 `docs/prototypes/chapter1-monochord.html` の配置を基準にする（要件7.1）。三角形の画面と同じく、スクロールせずに1画面、横向きにも対応する。

| 場所 | 中身 |
|---|---|
| 上 | 見出し、5つの星（1-1〜1-5）、お題の説明（例「5度上の音」） |
| 中央 | 一弦の琴（横に張った1本の弦、金色の駒、目盛り）。合格した比は弦の上に残す |
| 下 | 「お題を聞く」「弦をはじく」「重ねて鳴らす／止める」、微調整つまみ、揺れメーター（遊び方による）、合格までの保ちのバー |

- 色と質感は、今の遊ぶ画面と同じ色の名前（`:root`）を使う。深緑への変更（Codex の部品待ち）のときに、三角形の画面と一緒に変わる。
- 駒の位置は、面に入るたびに答えから少し離した位置に置く（試作と同じ）。

## 6. 自動テスト

- 1-1〜1-5 の答えの位置で、揺れが0になる（周波数がお題と一致）
- 揺れが1秒に1回未満を1秒保つと合格、途中で1回以上になると数え直し
- 駒の動く範囲（試作：弦の 0.30〜0.98）の中に、すべての答えがある
- 流れ：連続プレイで、序 → 第1章 → 謎（仮）→ 第2章 の順に進む

## 7. この段階でしないこと

- 章末の謎（盾の封音）、第3章、最終章の中身（段階5）
- 序の絵・セリフ・鐘の音（段階6。絵は Codex）
- 進み具合の保存（段階7）

## 8. 決めてほしいこと

1. **連続プレイの始まり**：序（仮）→ 第1章 から始める形でよいか。今の「すぐ三角形の8つの星」は、選択プレイの第2章から遊べる。
2. **第1章の弦全体の音**：試作どおり G3（196Hz）に固定してよいか（第1章を曲のどこに置くか Q-09 は未決のため、仮の値）。
3. **重ねて鳴らすときの音色**：鳴らし続ける音なので、今の音色からオルガン（音量が落ちず、揺れが聞き取りやすい）を仮に使ってよいか（A区分。実機で聞いて変えてよい）。

## 9. 決まったこと（2026-11-14 発案者：8章の3点は OK）

連続プレイは序（仮）→ 第1章 から始める。第1章の弦全体の音は G3（196Hz）に固定（仮の値）。重ねて鳴らす音色はオルガン（仮）。
