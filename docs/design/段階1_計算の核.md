## 2. 考え方（なぜこう作るか）

### 2.1 判定はすべて整数で行う

要件5章「整数の判定は整数のまま行い、小数の誤差を出さない」に従う。小数を使うのは、音を鳴らす周波数と、揺れの値（Hz）だけにする。

### 2.2 √2 の付く辺も、整数だけで判定できる

**仕組み：** 長さを「整数部分 n」と「√2 が付くか」の組で持つ（要件5章）。この長さの2乗は必ず整数になる（n√2 の2乗は 2n²）。

- 長さの大小、直角かどうか、比が同じかどうかは、2乗どうしを比べれば整数だけで決まる。
- 「閉じる」だけは長さの和を比べるので、2乗では済まない。そこで「整数 ＋ 整数×√2」の形の数が正か負かを、整数だけで決める方法を使う（√2 が無理数なので、この形の数は2乗を比べれば符号が決まる）。

**小数で計算すると、実際に間違える（計算で確認）：** 3√2・4√2・7√2 は「短い2本の和 ＝ 最長」なので閉じないのが正しい。ところが小数で計算すると、誤差で「閉じる」と出る。3本とも整数部分が2〜24の「a√2・b√2・(a＋b)√2」の組では、21通りで間違えた。

### 2.3 数の大きさ

棒は2〜24。2乗どうしを掛けても約130万で、JavaScript の数が誤差なく扱える範囲（約9000兆まで）に十分収まる。

## 4. 発見の判定（要件5章）

自分の3本を短い順に x ≤ y ≤ z、お題を a ≤ b ≤ c とする。比べるときは、すべて2乗の整数で比べる。

| 発見 | 判定 |
|---|---|
| 閉じない三角形 | `closes` が「閉じない」 |
| 直角の三角形 | x² ＋ y² ＝ z²（直角なら必ず閉じる） |
| 1オクターブ違い | 3本とも、お題のちょうど2倍（2a・2b・2c）か、3本ともちょうど半分 |
| 長調と短調の鏡写し | x・c ＝ y・b ＝ z・a。かつ、お題と同じ比（x:y:z ＝ a:b:c）ではない |

**鏡写しの式の意味：** 周波数は長さに反比例するので、お題の周波数の比（低い順）は 1/c : 1/b : 1/a。自分の長さの比 x:y:z がこれと同じ、というのが要件の「長さの比が、お題の周波数の比と同じ」。両辺に a・b・c を掛けると上の式になる。

**例（計算で確認）：** お題 4・5・6（短三和音、周波数 10:12:15）に、自分 10・12・15 を選ぶ → 10×6 ＝ 12×5 ＝ 15×4 ＝ 60 で鏡写し。逆向き（お題 10・12・15 に 4・5・6）も同じく成り立つ。

## 5. テスト（`tests/core-*.test.js`）

**要件5章の固定例（AC-01）**

| 辺の長さ | 確かめること |
|---|---|
| 3・4・5 | 比 12:15:20、短三和音の第1転回形（ラ・ド・ミで、ドが一番下）、閉じる、直角 |
| 4・5・6 | 比 10:12:15、短三和音の基本形、閉じる |
| 10・12・15 | 比 4:5:6、長三和音の基本形、閉じる |
| 1・2・3 | 閉じない（和が等しい） |
| 2・3・6 | 閉じない |
| 6・6・6√2 | 整数比なし。同じ音2つと、その増4度上（周波数の比 √2）。閉じる、直角 |

**そのほか**

- 和が等しいときの境目：1・2・3、3√2・4√2・7√2 は閉じない（後者は小数では間違える組）。上の21通りすべても確かめる
- √2 の大小：6√2 は 8 より長く、9 より短い
- 正解：並び順が違っても正解、同じ長さの重なり（6・6・6√2）も一致、1オクターブ違い（6・8・10 に対する 3・4・5）は不正解
- 発見4種：上の例（鏡写し）、3・4・5 と 6・8・10（1オクターブ違い）、直角、閉じない
- 揺れ：同じ組なら 0・0・0。「澄」「遠い」の境目（0.6・15）
- 計算の核が、画面・音・保存を読み込んでいないこと（`src/core/` の読み込み先を検査する）

## 9. 実装の結果と、分かったこと（2026-11-14）

**作ったもの：** `src/core/` に `length.js`・`pitch.js`・`chord.js`・`judge.js` と、整数の道具 `integer.js`（最大公約数・最小公倍数・いちばん大きい素因数）。`chordOf` は設計に加えて、最低音から最高音までの半音の数 `span` も返す（段階2の「広がり16半音以内」に使う）。

**テスト：** 37件すべて合格（段階0の5件を含む）。固定例6行（AC-01）、和が等しい21通り、発見4種、計算の核の読み込み先の検査を含む。

**分かったこと1：減三和音の数え上げは、要件の文だけでは再現できない。** 2〜24・長さはすべて違う・閉じる・広がり16半音以内・純正さ（長短は5まで、減は7まで）で数えると、長三和音・短三和音は要件5章の数とすべて一致した。ところが減三和音は、要件の「第2転回形2通り」に加えて、基本形（例 3・5・7）や第1転回形（例 7・10・12）も見つかった。試作のコードを読むと、要件に書かれていない条件「各音が平均律の半音から20セント以内」がある。これで 7:6（267セント）・7:3 などを含む和音が外れ、要件の数になる。どの和音を出題に使うかは段階2で決めるので、段階2の設計メモで、この条件を要件に足す案を出す。

**分かったこと2：固定例 6・6・6√2 の文の向き。** 要件5章の表「同じ音2つと、その増4度上（比√2）」は、「同じ音2つの上に、増4度上の1音」とも読める。計算では逆で、6√2 がいちばん長いので低い1音になり、その増4度上に 6・6 の同じ音2つが鳴る（最終章の表の「シ・ファ・ファ（6√2・6・6）」と同じ）。テストは計算と最終章の表に合わせた。要件の文は書き換えていない。
