# 案内カードと両章の終了トースト（v0.9.14）

2026-11-15。発案者の1297〜1301.jpg、1303.jpgの指摘に対応。共有先の物語設計コミット87462c3も保持して作業した。

## 変更と決定

- 第1章の見出しは章名とモードを縦に並べ、案内・タイトルボタンが横にはみ出さないようにした。
- 案内は「手順・操作ボタン／精霊・本文／進行」の3段。操作ボタンで本文幅を狭めず、6セグメントはカード下端に固定。カードと盤面も手順変更で動かさない。小型・横では本文を内部スクロールできる。
- メーターは案内の重ね合わせ・揺れの説明・調律中に静的な金枠で強調。非表示を選んだら表示ボタンを案内する。使えないモードでは強調しない。補足は「使えるモードでは、メーターも任意で表示できます。」
- fineは実際にFINE_BEAT未満を監視して一度切り替える仕組みを保持し、「揺れがゆっくりになってきたら、つまみで仕上げよう。」という条件文にした。再び速くなっても、現在の速さを断定しない。
- チュートリアルはモード未選択でも入るため、合格の説明に数値を固定しない。「揺れを合格の範囲に合わせ、指定の時間保つとクリア。」と簡潔にした。判定の値や計算自体は変更していない。
- 両章の結果を、見出し・スクロールする本文・固定した操作ボタンに分離。共通result-layout.jsで、小さい操作欄でも見出し・ボタン・上下余白・本文2行分を確保する。本文が長くてもボタンを押し出さない。
- 第2章は従来の光る導線に加え、2-1だけ短い吹き出しを盤面の下に表示。お題→棒→辺→回答に合わせて内容を変える。タップで試聴、ダブルタップで使用、直接ダブルタップも可能、使用中をダブルタップで解除と説明。2回タップ設定ではその設定に合う説明にする。×で閉じられ、次の小節・クリア後・メニュー・結果表示中には出さない。記録は増やさない。

## 検証の区別

preview.htmlとsilent-main.jsは、実際の画面コントローラーに無音の音源代役を渡す検証専用ページ。DOMの差し替えや隠れたゲーム状態の書き換えはせず、ボタン・ドラッグと既存?checkの答え確認から操作した。公開ビルドにはdocs/を含めない。

これらはPC上の画面・操作検査で、実機PWAの見え方や聴感の合格を意味しない。通常ページで鳴らした検証音は停止済み。以後の音を使う検査も終了時に止める。
