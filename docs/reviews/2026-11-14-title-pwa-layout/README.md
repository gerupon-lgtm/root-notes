# タイトルのPWA相当表示をPRISMへそろえる（v0.9.12）

2026-11-14。発案者の添付1293.jpg（PRISM）と1292.jpg（ROOT v0.9.10）の差に対応。途中でClaudeの作業完了を確認し、最新版488b192（v0.9.11）のチュートリアル変更を取り込んでから修正した。

## 決定した配置

発案者の選択は「最下段とフッタを下端にそろえる（背景を広く見せる）」。3段のボタン数・入口・ROOTの配色と背景を保ち、縦画面のロゴ位置、ボタンの寸法・文字をPRISMにそろえる。最上段のボタンをPRISMと同じ高さへ移す案は採用しない。

## 再現と原因

同じ412×844の実ブラウザでDOMの位置と算出されたスタイルを比較した。修正前はシリーズ表記とロゴがPRISMより42px下、最上段ボタンが98.0625px下、ボタン文字15px/500（PRISMは14px/400）、選択の段44px（PRISMは48px）だった。before-measurements.jsonを参照。

PWA機能で絵が変わったのではなく、使える高さが増えたとき、ボタンを減らした分が上側の中央配置にも配分されることが原因。背景のための空白もPRISMの95pxに対して109.71875pxとなり、フッタの余白・文字・高さも異なっていた。ROOTのタイトルにはdisplay-mode別の配置変更はなかった。

## 変更

src/ui/style.cssのタイトル内に限定。上側の空間は、PRISMから省いた2段分（通常104px、小型86px）を差し引いて配置し、空いた場所は背景として残す。空間の基準、文字14px/400/1.4、通常44px・選択の段48px、フッタ10px/14pxをPRISMにそろえた。低い横画面は全ボタン34px、説明一覧は画面内でスクロール可能。

package.jsonとsrc/version.jsを0.9.12へ更新。ビルドはv0.9.12の資材パスとworkerの照合値を生成するので、キャッシュバスターも更新される。ゲームの計算・音・保存・チュートリアル処理・画像・PWAの仕組みは変更していない。

## ブラウザ検査

layout-matrix.jsonは実ページの位置・寸法・算出スタイル。各条件でPRISMとROOTを同じブラウザ／タブ／表示寸法で読み、書体の読込を待って比較した。

- 縦6条件：412×844、412×915、412×760、390×844、360×640、320×568。シリーズ表記・ロゴ・フッタのy座標の差は全て0px。
- 横2条件：915×412、915×340。ボタンの高さ・文字・太さ・行高・角丸が一致。左にロゴ、右にメニューを保ち、全体のはみ出しなし。
- 横向きのロゴとフッタの絶対位置は、PRISMの別の省スペース配置へ合わせる対象にはせず、ROOTの2列配置を保持した。
- 全8条件で表示寸法一致、ページのはみ出しなし、ボタンの高さと文字の一致を合否検査。
- 追加：500×500、768×1024、1366×768で全体のはみ出しなし。extra-layout-checks.jsonを参照。
- 説明欄：915×340で上端4px・高さ170px、内容は内部スクロール。説明の開閉、チュートリアル（最新の6手順）、選択プレイの章選択、連続プレイの序、タイトルへの復帰を確認。警告・エラーログなし。

この検査はPC上で画面寸法を合わせたもの。インストール済みAndroid/iPhoneでの修正後の配置・安全領域・音・使い心地は未確認。実機の合格とは区別する。
